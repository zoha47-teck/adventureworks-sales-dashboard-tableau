# AdventureWorks Sales Performance Dashboard

## Overview
This project presents an interactive Tableau dashboard analyzing AdventureWorks sales data from 2020–2022.

## Objectives
- Analyze revenue and profit
- Identify top-performing products
- Evaluate customer performance
- Monitor sales trends over time
- Compare product categories

## Dashboard Features
- Revenue KPI
- Profit KPI
- Total Orders
- Total Customers
- Profit Margin
- Monthly Revenue Trend
- Top 10 Products
- Revenue by Category
- Top Customers

## Tools Used
- Tableau
- AdventureWorks Dataset
- Data Modeling
- Calculated Fields
- Dashboard Design
